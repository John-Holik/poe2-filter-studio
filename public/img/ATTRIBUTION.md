# Item Image Attribution

All item images referenced by `manifest.json` are © Grinding Gear Games.

This tool does **not** bundle, copy, or redistribute any game art. `manifest.json` contains only URLs pointing to images hosted on Grinding Gear Games' official CDN (`https://web.poecdn.com`), and the app loads them client-side at runtime — the same way the official trade site (pathofexile.com/trade2) serves item icons. If an image is unavailable, the app falls back to a plain glyph.

Every URL was sourced from official Grinding Gear Games API responses (the trade2 static-data and trade search APIs) and verified live before inclusion.
